# iQuit

A fresh start without a restart. An [R6.ai](https://r6.ai) product.

iQuit sits in the menu bar and lets you quit one, some, or all running apps from one tidy spot. Hold Option to force quit. Unused apps can quit themselves after a timeout you choose.

## Build

```bash
chmod +x Scripts/build-app.sh Scripts/test.sh Scripts/swiftc-manifest-fix
Scripts/build-app.sh
open dist/iQuit.app
```

Requires macOS 14+ and Swift 6.

Run the tests with `Scripts/test.sh` (wraps `swift test --disable-xctest`, which is what a Command Line Tools-only install supports; XCTest is not needed). Both scripts set `SWIFT_EXEC_MANIFEST` to `Scripts/swiftc-manifest-fix` so the package manifest compiles on recent Command Line Tools without affecting the toolchain used for the build itself.

## Use

- Click the menu bar icon to see running apps, with optional CPU and memory. Helper processes (renderers, GPU and network helpers) are folded into their parent app, so Electron and browser apps show one row with their combined usage.
- Quit one app, selected apps, or everything iQuit is allowed to close. Apps can save first.
- Hold **Option** to turn every Quit control into Force Quit.
- A row shows **Quitting…** while an app is closing. If it is still running after a few seconds (an unsaved document, for example) the row switches to **Still running** with a **Force** button.
- After a quit finishes, a **Reopen** bar appears for a moment so you can undo it.
- Use the ⋯ menu on a row for **Never Quit**, **Quit & Reopen**, or **Reveal in Finder**. Toggle background apps from the footer.
- Preferences live under **Preferences…** (`⌘,` from the right-click menu): launch at login, auto-quit, shortcuts, menu bar icon, and appearance.

### Keyboard

The search field has focus as soon as the popover opens; just start typing to filter.

| Key | Action |
| --- | --- |
| ↑ ↓ | Move the focus bar between rows |
| ↩ | Quit the focused app (Force Quit with ⌥) |
| Space | Select or deselect the focused row (when the search field is empty) |
| ⌘A | Select all |
| ⌘⌫ | Quit selected apps, or the focused app if nothing is selected |
| Esc | Cancel Quit All, clear the search, or close the popover |

### Auto Quit

Auto Quit closes regular apps that have not been frontmost for the chosen time. Each row it applies to shows a countdown. It skips the frontmost app, Never Quit apps, music apps (if enabled), apps with a window on screen (optional, on by default), and apps that refused to quit until you use them again. When an app is auto-quit, a notification with a **Reopen** action is posted (optional, on by default; requires running from `dist/iQuit.app`).

### Menu bar

Choose between the colour logo and a monochrome template icon that follows the menu bar appearance, and optionally show the number of running apps next to the icon.

## Automation

```bash
dist/iQuit.app/Contents/MacOS/iQuit --quit-all
dist/iQuit.app/Contents/MacOS/iQuit --force-quit-all
dist/iQuit.app/Contents/MacOS/iQuit --quit TextEdit
dist/iQuit.app/Contents/MacOS/iQuit --list
dist/iQuit.app/Contents/MacOS/iQuit --status
```

`--quit` accepts an app name, a bundle identifier, or a unique name prefix.

URL scheme:

```
iquit://quit-all
iquit://force-quit-all
iquit://quit?name=TextEdit
iquit://list
```

Shortcuts: **Quit All Apps**, **Force Quit All Apps**, **iQuit Status**. The Shortcuts metadata is only generated by an Xcode build, so these actions do not appear in Shortcuts.app when the bundle is produced with `Scripts/build-app.sh`.

## Limits

iQuit will not quit Finder, Dock, or other protected system processes, and it hides Apple's own background agents and daemons from the background list. Some background apps relaunch themselves after quitting. Force quit skips save prompts.
